# 小小單車學習島

適合幼兒園大班的繁體中文 3D 學習遊戲。沿著單車路線收集數字、注音和簡單國字，現在有 **24 關挑戰旅程**，並保留原本三項自由練習。

## 24 關挑戰

關卡地圖分成四段、每段六站：

1. **數字果園**：數水果、認數字，練習數量和符號配對。
2. **注音森林**：看圖找出詞語開頭的注音符號。
3. **國字小鎮**：用生活圖像認識「日、山、水、木、火、月」等簡單國字。
4. **綜合山道**：交錯複習數字、注音和國字。

玩法輪替包括 **連連看、翻牌記憶配對、泡泡靶場、車輪消消樂、終點接力**。泡泡靶場以點擊泡泡作答，不使用武器；車輪消消樂以交換相鄰圖塊找三連，成功後只清除命中的圖塊，保留同欄圖塊下落並補入新格。地圖採單車路線節點，每關有自己的名稱、任務故事和操作目標；完成一關即可解鎖下一關，已完成的關卡可重玩，最佳里程星數不會倒退。錯誤答案不扣分、不鎖關，沒有倒數計時。

進度與音訊偏好保存在目前瀏覽器，不需要登入或網路連線。首頁底部的 **自由練習** 可繼續玩數字、注音和圖像認字三個原有短課程。騎士插圖、3D 小島、環形車道和三個學習路標均保留。

## 配樂、音效與語音

遊戲使用 Web Audio 即時合成柔和循環配樂與配對、泡泡、消除等回饋音效；不需下載音檔，總音訊開關可記憶設定。音訊只在第一次使用者操作後播放。

語音導讀使用裝置／瀏覽器內建語音合成，向語音引擎指定繁體中文 `zh-TW`，朗讀挑戰說明、題目、答案選項與鼓勵提示。關卡中的「重聽」按鈕可再次播放任務導覽；語音可以獨立開關。實際音色與繁體中文語音是否可用依瀏覽器／裝置而定；沒有語音合成支援時仍可依文字遊玩。遊戲不錄音，也不使用麥克風。

## 開發與測試

```bash
pnpm install
pnpm dev -- --host 0.0.0.0
pnpm typecheck
pnpm test
pnpm build
pnpm smoke  # build 後以 Chromium 驗證 24 關、五種玩法、存檔和手機觸控
```

## 專案結構

- `src/game/campaign.ts`：24 關資料、挑戰描述、學習配對與題庫。
- `src/game/campaign-rules.ts`：解鎖、星數、棋盤和消除規則。
- `src/ui/campaign-ui.ts` / `campaign-ui.css`：進度地圖與五種玩法介面。
- `src/ui/learning-ui.ts`：原有自由練習、語音導讀和本機紀錄。
- `src/engine/audio.ts`：可關閉的合成配樂與遊戲音效。
- `src/game/learning-scene.ts`：3D 小島、車道、浮空學習路標及騎士移動。
