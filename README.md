# 小小單車學習島

適合幼兒園大班的繁體中文 3D 學習遊戲。孩子戴好安全帽，沿著小島單車路線挑戰三段短旅程：在果園點數、在森林找出注音符號，再用圖片記住簡單漢字。各關有清楚的任務說明；答對一道題，騎士就前進一個路標，答錯沒有扣分，可以慢慢再試。

主角使用你提供的騎士插圖，去背後放進 Three.js 場景；浮空小島、環形車道、分色天空，以及標示「1、2、3」「ㄅ、ㄇ、ㄍ」「日、山、水」的學習路標，會隨關卡呈現不同氣氛。遊戲以大按鈕操作，支援觸控與鍵盤，並將完成進度保存在目前瀏覽器。沒有登入、排行榜或付款功能。

## 三種旅程

- **數字果園**：聽任務介紹，數水果、星星與其他圖卡，再選出正確數字。
- **注音森林**：看圖想想詞語開頭的聲音，選出第一個注音符號。
- **圖像認字屋**：配對圖片與「日、山、水、木、火、月」等簡單漢字，並閱讀圖像記憶提示。

每題有即時友善回饋，不設限時、不扣分。答對會讓騎士在 3D 車道上前往下一站，完成整關可重玩或回到選單。

## 語音引導

使用裝置／瀏覽器內建語音合成，向語音引擎指定繁體中文（`zh-TW`），朗讀關卡任務、題目與答案選項，以及答題後的鼓勵提示。進入關卡後會先介紹任務並帶出第一題；每題旁的「聽題目」按鈕可重播。首頁及關卡頂部的喇叭按鈕可開啟或關閉語音，偏好設定會保存在目前瀏覽器。語音預設開啟，但只會在使用者開始關卡後播放。實際音色與是否提供繁體中文語音依瀏覽器／裝置而定；沒有語音合成支援時，仍可依畫面文字遊玩。遊戲不錄音、不使用麥克風，也不內嵌額外音檔；朗讀由裝置語音引擎處理。

## 開發與測試

```bash
pnpm install
pnpm dev -- --host 0.0.0.0
pnpm typecheck
pnpm test
pnpm build
pnpm smoke  # build 後以 headless Chromium 驗證桌面及手機互動、關卡語音與路標
```

## 專案結構

`src/game/learning-scene.ts` 管理 3D 小島、環形車道、關卡學習路標及騎士移動；`src/game/lessons.ts` 保存題庫和關卡介紹；`src/ui/learning-ui.ts` 負責關卡、答題、繁體中文語音引導和進度；`src/game/tuning.ts` 保留供預覽工具使用的相機參數。主角圖像在 `assets/images/bike-rider.png`，遊戲 favicon 在 `assets/share/favicon.png`。
